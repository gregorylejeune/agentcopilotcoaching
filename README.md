# agentcopilotcoaching

Public repository of Copilot agent prompts and coaching tools for growing development teams.

Focus areas:
- Structured 1:1 meetings
- Note-taking and action item tracking
- Addressing team member concerns
- Career development and team growth strategies (skills, hiring, retention, culture)
